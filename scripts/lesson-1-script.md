# Fundamentos de Java

Bienvenidos al curso de **Fundamentos de Java para Principiantes**. En este pequeño curso de aproximadamente una hora aprenderemos las bases para iniciarnos en el mundo de la programación con Java, incluyendo una introducción a la programación orientada a objetos.

## ¿Pero primero, qué es programar?

Imaginen que tienen un robot que no sabe hacer nada. Para que les prepare un sándwich, necesitan darle instrucciones exactas:

1. Toma una rebanada de pan.
2. Unta la mantequilla.
3. Toma otra rebanada de pan.
4. Junta ambas rebanadas.

Programar es básicamente eso: darle órdenes lógicas a una computadora paso a paso, utilizando instrucciones claras que pueda entender para resolver un problema o crear algo útil o divertido.

## Ahora, ¿cómo nos comunicamos con una computadora?

Por ejemplo, si quieres hablar con alguien de otro país, necesitas un idioma en común. Con la computadora sucede algo parecido. Para ello existen los **lenguajes de programación**.

Un lenguaje de programación es el puente entre nuestro lenguaje humano y el lenguaje de la máquina, que en realidad solo entiende ceros y unos.

Existen miles de lenguajes de programación, pero nosotros aprenderemos uno de los más populares y utilizados en el mundo: **Java**.

Java es un lenguaje robusto, seguro y multiplataforma, utilizado por millones de desarrolladores para crear aplicaciones, sitios web, sistemas empresariales y mucho más.

## ¿Dónde se utiliza Java?

Java se encuentra detrás de muchas aplicaciones, plataformas y servicios que usamos diariamente. Por ejemplo, la versión original de Minecraft fue desarrollada en Java, y empresas como Spotify, Netflix y muchas otras utilizan Java en distintos componentes de sus sistemas para brindar servicios a millones de usuarios.

## Pero ahora, ¿cómo se ve Java realmente?

Este es un programa sencillo escrito en Java que imprime en la consola la icónica frase **"Hola Mundo"**.   

```java
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}
```
Por ahora puede parecer un conjunto de palabras extrañas, pero no te preocupes. A lo largo del curso iremos entendiendo cada línea de este código y, antes de terminar, serás capaz de crear tu propio programa desde cero.
