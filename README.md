# Fundamentos de Java para Principiantes

¡Bienvenido al repositorio del curso **Fundamentos de Java para Principiantes**!

En este curso, dirigido a estudiantes de entre **12 y 17 años**, aprenderás los conceptos básicos de programación utilizando **Java**, incluyendo variables, estructuras de control, métodos y Programación Orientada a Objetos.

## Ubicación de las Lecciones

Cada lección cuenta con su propia carpeta dentro de las carpetas `/starter-files` y `/completed-examples`.

| Lección    | Tema                                            | Carpeta     |
| ---------- | ----------------------------------------------- | ----------- |
| Lección 1  | Fundamentos de Java                             | `lesson-1`  |
| Lección 2  | ¿Qué es la Programación Orientada a Objetos?    | `lesson-2`  |
| Lección 3  | Hello World, Variables y Operadores             | `lesson-3`  |
| Lección 4  | Decisiones con if-else                          | `lesson-4`  |
| Lección 5  | Bucles                                          | `lesson-5`  |
| Lección 6  | Métodos                                         | `lesson-6`  |
| Lección 7  | Clases y Objetos                                | `lesson-7`  |
| Lección 8  | Métodos del Objeto                              | `lesson-8`  |
| Lección 9  | Encapsulamiento y Arrays de Objetos             | `lesson-9`  |
| Lección 10 | Proyecto Final: Sistema de Registro Estudiantil | `lesson-10` |

Contiene los archivos iniciales utilizados al comienzo de cada lección. Cada carpeta contiene el código base que servirá como punto de partida para los ejercicios desarrollados durante el curso.

## Cómo Utilizar este Repositorio

1. Ingresa a la carpeta correspondiente a la lección que deseas estudiar.
2. Abre los archivos dentro de `/starter-files`.
3. Sigue las instrucciones del video o la clase.
4. Completa el ejercicio propuesto.
5. Compara tu solución con los archivos ubicados en `/completed-examples`.
